2. 预测曲线对比图数据

figures/forecast_curves/forecast_curves_data_from_json.csv

数据来源

该文件由 figures/forecast_curves/fig_forecast_curves_comparison_data.json 转换而来。 原始 JSON 由 src/visualization/plot_forecast_curves.py 在绘图时导出， 包含了三种物资在五种模型上的预测值和真实值。

列说明

列名 类型 说明
material_id str 物资编号：001（10kV油浸式变压器）、002（架空绝缘导线）、003（智能电表）
material_name str 物资中文名称
model str 模型名称：真实值、本文框架、VMD-LSTM、XGBoost、LSTM、ARIMA
time_step int 测试集时间步序号（从0开始）
value float 需求量值（原始物理单位）

数据格式说明

采用 长格式（Tidy Data），每行表示某个物资在某个时间步下某个模型的预测值（或真实值）。 通过 material_id + model 的组合可以筛选出任意一条曲线数据。 三种物资 × 6种模型（含真实值）共 1,134 条记录。

3. VMD 信号数据

figures/vmd_visualization/combined_final/vmd_signal_data_from_json.csv

数据来源

该文件由 figures/vmd_visualization/combined_final/fig_vmd_combined_multi_material_final_data.json 中的 _signal_table 字段转换而来。包含了三种物资在全时间序列上的原始需求值和 VMD 分解后的四个模态分量值。

列说明

列名 类型 说明
material_id str 物资编号（001 / 002 / 003）
material_name str 物资中文名称
date str 时间日期（YYYY-MM-DD 格式，月频数据）
demand float 原始需求序列值
IMF1 float VMD 第1模态 — 趋势分量
IMF2 float VMD 第2模态 — 低频分量
IMF3 float VMD 第3模态 — 中频分量
IMF4 float VMD 第4模态 — 高频分量

数据说明

四个 IMF 分量之和约等于原始 demand 值（VMD 重构决定系数 R² 接近 0.81~0.97）。 三种物资的全序列数据合并在一个 CSV 中，通过 material_id 区分，每种物资 372 条时间记录。

4. VMD 统计特征数据

figures/vmd_visualization/combined_final/vmd_imf_stats_from_json.csv

数据来源

该文件由 JSON 中的 _imf_stats 和 _reconstruction 字段转换而来。 提供了三种物资各 IMF 模态的数理统计指标，包括方差贡献率、主导周期频、VMD 重构精度等。

列说明

列名 类型 说明
material_id str 物资编号
material_name str 物资名称
IMF str IMF 编号（IMF1 / IMF2 / IMF3 / IMF4）
label str 物理含义标签（趋势 / 低频 / 中频 / 高频）
mean float 该模态的均值
std float 该模态的标准差
var_pct float 方差贡献率（占原始信号总方差的百分比）
dominant_freq float 主导频率
dominant_period_months float 主导周期（月）
reconstruction_R2 float VMD 重构决定系数 R²（每行重复）
reconstruction_RMSE float VMD 重构均方根误差（每行重复）
reconstruction_MAE float VMD 重构平均绝对误差（每行重复）

数据说明

每条物资对应 4 行（4 个 IMF），共 12 行数据。reconstruction_* 三列在同一物资的 4 行中重复出现， 表示该物资全序列 VMD 重构的整体精度指标。

5. 使用示例

Python 读取示例

import pandas as pd

# 读取预测曲线数据
df_forecast = pd.read_csv('figures/forecast_curves/forecast_curves_data_from_json.csv', dtype={'material_id': str})
print(df_forecast.head())

# 筛选物资 001 的"本文框架"预测值
df_001_ours = df_forecast[
    (df_forecast['material_id'] == '001') &
    (df_forecast['model'] == '本文框架')
]

# 读取 VMD 信号数据
df_vmd = pd.read_csv('figures/vmd_visualization/combined_final/vmd_signal_data_from_json.csv', dtype={'material_id': str})
print(df_vmd.head())

# 读取 VMD 统计特征
df_stats = pd.read_csv('figures/vmd_visualization/combined_final/vmd_imf_stats_from_json.csv', dtype={'material_id': str})
print(df_stats.groupby('material_id')[['var_pct', 'dominant_period_months']].describe())

Excel 打开方式

CSV 文件使用 UTF-8-BOM 编码，直接用 Excel 打开即可正常显示中文：

  1. 打开 Excel → 数据 → 自文本/CSV
  2. 选择对应的 CSV 文件，编码选择 UTF-8
  3. 使用筛选功能按 material_id、model 等列快速过滤
  4. 或使用数据透视表进行汇总分析

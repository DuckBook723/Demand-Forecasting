PIPELINE

端到端数据流水线

从原始数据仿真到模型训练评估的完整流程，严格遵循时间顺序避免信息泄漏

数据生成与预处理 Phase 1

日度仿真→月度聚合策略，生成符合业务规律的电网物资需求数据，经VMD分解、清洗归一化后输出标准化训练集。

generate_data.py
日度仿真引擎：模拟20种物资5区域需求，含项目脉冲/连续消耗/零星随机三种模式，月度聚合后注入缺失与异常。
日度仿真 BOM联动 因果调制
preprocess.py
数据清洗+VMD分解+归一化：仅在训练集拟合VMD/缩尾分位数，验证测试集通过AR外推，杜绝信息泄漏。
VMD分解 AR外推 MinMax归一化
dataset.py
PyTorch数据集：支持4种数据模式(vmd_dae/no_vmd/no_vmd_raw/no_dae)，滑动窗口生成样本对，自动识别IMF与特征列。
GridMaterialDataset DataLoader 4种模式
diagnose_data.py
数据质量诊断：零需求比例、需求分布、特征-需求斯皮尔曼相关性、自相关性、缺失值比例检查。
相关性诊断 ADF检验
特征工程 Phase 2

双重特征筛选（Spearman+随机森林）→ DAE去噪降维，将高维外部特征压缩为鲁棒低维表示。

feature_selector.py
双重筛选：Spearman相关性初筛(阈值0.1) + 随机森林重要性精筛(Top-7)，输出selected_features.json。
Spearman ρ RF Importance Top-N
dae_encoder.py
去噪自编码器：5维→[16,8]→3维编码+解码重构，加噪训练提升鲁棒性，支持端到端联合优化模式。
DenoisingAE 5→3降维 端到端训练
模型构建 Phase 3

VMD-CAT-BiLSTM核心模型：VMD多尺度分解 + CA-TCN局部特征 + TA-BiLSTM全局依赖 + 门控融合 + 预测头。

ca_tcn.py
通道注意力TCN：因果空洞卷积保证时序因果性，ECA通道注意力动态调整通道重要性，堆叠4层指数膨胀。
CausalConv1d ECA-Net 残差连接
ta_bilstm.py
时间注意力BiLSTM：双向LSTM捕获前后向依赖，时间注意力机制自动识别关键时间步，LayerNorm稳定训练。
BiLSTM TemporalAttention LayerNorm
fusion.py
门控融合+预测头：Sigmoid门控动态平衡局部/全局特征贡献，多层MLP+Sigmoid输出(0,1)范围预测值。
GateFusion PredictionHead Sigmoid
vmd_cat_bilstm.py
主模型：管理K个SubNet并行处理各IMF，支持参数共享与端到端DAE训练，累加预测值输出最终结果。
VMDCATBiLSTM SubNet 参数共享
训练与评估 Phase 4

完整训练循环：余弦退火学习率、梯度裁剪、早停机制，支持VMD双路与单路两种模型类型，含DAE重构辅助损失。

trainer.py
训练管理器：train_one_epoch + validate + calculate_metrics，余弦退火LR，早停，RMSE/MAE/MAPE/R²四指标评估。
CosineAnnealing EarlyStopping Metrics
train.py
训练入口脚本：检查数据就绪→解析超参→构建DataLoader→初始化模型→启动训练，保存最优权重与训练记录。
argparse checkpoint
evaluate_model.py
通用评估函数：支持VMD/Single两种模型类型，统一反归一化，返回指标+真实值+预测值+参数量。
反归一化 n_params
实验验证 Phase 5

5组消融实验验证各组件贡献 + 3个基线模型公平对比，统一指标评估与结果汇总。

run_ablation.py
消融实验统一运行脚本：依次训练Full+A1~A5共6个模型，自动适配端到端DAE模式，汇总指标到CSV。
6组实验 自动汇总
diagnose_dae.py
DAE诊断工具：独立测试DAE编码器→测试VMDCATBiLSTM forward(use_dae=True)→对比w/o DAE模式。
维度验证 Forward测试

BASELINES

基线模型对比

经典统计方法与机器学习方法，使用相同数据划分与评估指标确保公平对比

ARIMA / SARIMA
经典统计方法
  • 支持自动寻阶（pmdarima.auto_arima）
  • 滚动预测：逐步加入真实值重训
  • ADF平稳性检验 + AIC/BIC信息准则
  • 季节性扩展：SARIMA(p,d,q)(P,D,Q,12)
  • 直接使用原始需求序列（无需特征）
LSTM
深度学习基线
  • 2层LSTM + 全连接输出层
  • 滑动窗口输入，支持外部特征
  • AdamW优化 + ReduceLROnPlateau
  • 梯度裁剪(max_norm=1.0)防爆炸
  • Sigmoid激活约束输出范围
XGBoost
梯度提升树
  • 丰富特征工程：lag/差分/滚动统计/时间特征
  • 超参数网格搜索（max_depth/lr/n_estimators）
  • 早停 + 验证集RMSE监控
  • 特征重要性分析（Top-N + 类别贡献）
  • 需求非负约束：np.maximum(pred, 0)

1项目概述

1.1　研究背景

电网物资需求预测对保障电力系统安全运行与控制采购成本至关重要。10kV油浸式变压器作为配电网核心设备，其月度需求受宏观经济、气象条件、电网运行状态等多因素耦合影响，呈现多尺度非平稳特征，传统方法难以有效建模。

1.2　研究目标

构建一个融合信号分解、因果时序建模、双向长短期记忆与自适应特征筛选的混合深度学习框架，实现10kV油浸式变压器月度需求的精准预测。

1.3　核心创新点

  1. 4步共识特征筛选：综合Spearman、MI、RF置换重要性、SHAP四方法Borda排序，经相关性预筛→冗余剪枝→Kneedle截断，自适应消除无关与冗余特征
  2. CATCN模块：因果扩张时序卷积+ECA通道注意力，提取局部因果特征并引导时间注意力聚焦近期信息
  3. GateFusion门控融合：可学习门控自适应整合CATCN局部特征与BiLSTM全局特征
  4. 残差跳连预测头：预测需求增量而非绝对值，降低优化难度

1.4　最终性能

测试集核心指标：
· R² = 0.8858  |  MAE = 231.064  |  RMSE = 303.256  |  MAPE = 5.364%
· 较次优基线VMD-LSTM：R²提升2.23pp，MAE降低4.1%
· 较传统ARIMA：R²提升34.53pp，MAE降低43.4%

3.3.1　Step 1：数据清洗

方法：IQR异常检测（Q1−1.5×IQR ~ Q3+1.5×IQR），超出范围的值用前后均值线性插值替换。缺失值同样采用线性插值。

选择依据：IQR基于分位数，对偏态分布（需求呈右偏）比3σ准则更鲁棒；线性插值利用了序列的强时间连续性（lag-1 ACF=0.4087）。

3.3.2　Step 2：VMD多尺度分解

方法：变分模态分解（VMD），参数K=4、α=2000、τ=0、DC=0、init=1、tol=10−7。通过ADMM交替优化，将原始需求序列分解为4个带宽受限的IMF。

选择依据：VMD相比EMD/EEMD具有：①数学框架完备（变分优化，非经验递归）；②无模态混叠（频谱验证频带互不重叠）；③无端点效应（傅里叶域求解）。

VMD分解结果
IMF物理含义方差贡献主导周期
IMF₁趋势分量最大覆盖全序列
IMF₂低频振荡次之≈7.1月
IMF₃中频振荡较小≈3.5月
IMF₄高频振荡最小≈2.3月
重构精度：RMSE = 2.46×10⁻⁷, MAE = 1.84×10⁻⁷, R² ≈ 1.000000
→ 残差校正（按方差比例分配+二次微调）确保分解信息完全保留

Step 4.3 冗余剪枝：两两Spearman相关性|ρ|>0.85时，保留Borda分更高者。此步移除2个特征：

移除特征保留特征|ρ|Borda分(移除→保留)

Step 4.4 Kneedle自适应截断：归一化Borda得分曲线与均匀参考线的最大垂直距离处为肘部点，截断于第16个特征（ΔIMF₃被移除）。

筛选最终结果：
· 24维 → 16维 | 压缩率 33.3%
· 冗余对：4 → 1（降低 75%）
· 保留分组覆盖：经济2/3、VMD-IMF 4/4、时间4/4、动量4/5、电力1/4、目标1/1
· 气象0/3保留（全部被时间特征替代——月sin/cos编码了温度/风速的周期分量）
· 保留特征：投资增速、IMF₁、月cos、IMF₄、需求、GDP增速、IMF₂、月sin、ΔIMF₂、季度、ΔIMF₄、Δ需求、春节、ΔIMF₁、负荷、IMF₃

3.3.5　Step 5：标准化与序列化

标准化：StandardScaler（z-score），仅训练集拟合μ和σ，验证/测试集使用相同参数。

序列化：滑动窗口τ=12，步长1，构建(Xt-11,...,Xt) → yt+1样本-标签对。

选择依据：StandardScaler对极端值比MinMaxScaler更鲁棒；窗口τ=12对应1年周期，包含完整季节性信息，且lag-12的ACF=0.095已接近噪声水平。

4.2　CA-TCN模块（因果扩张时序卷积注意力网络）

CA-TCN由2个TemporalBlock组成，膨胀率d=1和d=2：

TemporalBlock内部结构
层配置输出维度
CausalConv1d × 2kernel=3, dilation=2l(B, 32, T)
BatchNorm1d每个Conv后接BN(B, 32, T)
ReLU + Dropout(0.3)激活+正则化(B, 32, T)
残差连接输入+卷积输出(B, 32, T)
ECA注意力GAP→Conv1d(k=5)→Sigmoid(B, 32, T)

关键设计：

  • 因果卷积：时刻t的输出仅依赖≤t的输入，避免信息泄露
  • 膨胀卷积：d=1感受野3步，d=2感受野扩大至7步，指数级扩大感受野
  • ECA注意力：仅5个参数的全局通道重标定，GAP→1D Conv(k=5)→Sigmoid
  • 线性投影：输入17→32维，输出32→16维

ECA行为分析：Block1（d=1）ECA均值≈0.500，接近均匀基线，短期特征层各通道贡献均衡；Block2（d=2）均值0.647且全部通道>0.5，高层特征经筛选后信息密度更高需整体增强。

4.3　TA-BiLSTM模块（时间注意力双向LSTM）

TA-BiLSTM内部结构
层配置输出维度
线性投影17→32(B, T, 32)
BiLSTMhidden=32, 双向, 1层(B, T, 64)
LayerNorm + Dropout(0.3)归一化+正则化(B, T, 64)
时间注意力FC(64→32)→Tanh→FC(32→1)→Softmax(B, 64)

时间注意力公式：

et = w⊤ tanh(W ẑt + b)
αt = softmax(et)
c = Σt αt ẑt   (上下文向量 = fglobal)

4.4　GateFusion门控融合

g = σ( MLP([ ProjL(flocal) ; ProjG(fglobal)]) )
ffused = g ⊙ ProjL(flocal) + (1-g) ⊙ ProjG(fglobal)

其中ProjL: 16→32, ProjG: 64→32, MLP: 64→32→32→32。门控g∈(0,1)32，逐维度自适应权衡局部与全局信息。

门控行为分析：
· 门控均值 ≈ 0.512，接近0.5 → 多数样本采用近均衡融合策略
· 这恰恰说明CATCN和BiLSTM两个分支提供了互补性等价的信息
· 消融验证：移除CATCN后R²从0.8858降至0.6711（ΔR²=−0.2147），确认局部分支不可替代

4.5　PredictionHead + 残差跳连

ŷt+1 = MLP(ffused) + 1.0 · yt

MLP结构：32→BN→ReLU→Dropout(0.3)→16→BN→ReLU→Dropout(0.3)→1。输出为需求增量Δ，加上最后一步真实需求yt得到最终预测。

6.2.1　VMD分解：性能基石（ΔR²=−65.30pp）

移除VMD后R²从0.8858暴跌至0.2328，降幅是第二关键组件的3.6倍。原始需求的多尺度非平稳性使LSTM同时拟合趋势、周期和噪声，梯度方向相互干扰。VMD将非平稳问题转化为4个相对平稳的子问题。

6.2.2　CATCN模块：注意力引导者（ΔR²=−18.12pp）

CATCN通过双重机制贡献：

  • 直接：局部因果特征提取（膨胀卷积感受野1~7步）
  • 间接：引导时间注意力聚焦近期信息
CATCN注意力引导数据（fig_catcn_contribution_analysis_data.json）：
· 近期3步(t-2~t)注意力占比：Full=37.3% vs w/o CATCN=22.1%（相对提升68.6%）
· 当前步t注意力：Full=0.1672 vs w/o CATCN=0.0684（Full为2.44倍）
· 逐样本胜率：54/75（72.0%）样本Full更优
· 改善幅度/劣化幅度 = 335.4/208.3 = 1.61（"大赢小输"分布）
· 改善均值=335.4台 | 劣化均值=208.3台

6.2.3　残差跳连：优化稳定器（ΔR²=−8.02pp）

残差跳连使模型只需学习增量Δy（平均|Δy|=784台）而非绝对值y（均值3931台），输出尺度降低约5倍，梯度更稳定。即使f(x)输出为0，预测值也等于上期需求（朴素预测基线）。

6.2.4　特征筛选：泛化保障（ΔR²=−5.26pp）

移除FS后使用24维特征，R²降至0.8332。筛选通过压缩33.3%维度和消除75%冗余对提升泛化能力。筛选结果的物理合理性进一步验证方法有效性：气象0/3保留（被时间替代），VMD-IMF 4/4保留，经济2/3保留。

6.2.5　组件协同效应

各组件独立贡献之和（65.30+18.12+8.02+5.26=96.70pp）大于Full与最差变体的实际差距（65.30pp），说明CATCN、Skip和FS的贡献建立在VMD分解基础上。VMD贡献了8/16=50%的入选特征（4个IMF+4个ΔIMF），是整个框架的必要前提。

8关键发现与结论

8.1　十大关键发现

发现1：VMD分解是整个框架的性能基石，移除后R²从0.8858降至0.2328（−65.3pp），降幅是第二组件的3.6倍。
证据：图6(b)消融对比 + 表3消融实验
发现2：CATCN通过双重机制贡献：直接提取局部因果特征+间接引导时间注意力聚焦近期。
证据：近期3步注意力占比+68.6%（图9a），当前步关注度2.44倍
发现3：CATCN的贡献呈"大赢小输"分布——改善幅度是劣化幅度的1.61倍，72%样本受益。
证据：fig_catcn_contribution_analysis_data.json
发现4：4步共识特征筛选将24维压缩至16维（33.3%），冗余对降低75%，且筛选结果物理合理。
证据：气象0/3保留（被时间替代），VMD-IMF 4/4保留
发现5：VMD分解的信息价值双重：既作为序列解耦手段（将非平稳转化为平稳），又作为IMF特征源（50%入选特征来自VMD）。
证据：16维中4个IMF+4个ΔIMF = 8/16
发现6：GateFusion门控均值≈0.512，反映局部-全局互补等价而非某一分支主导。
证据：门控数据 + 消融验证（移除任一分支R²均大幅下降）
发现7：需求序列呈三层时序结构：短期AR(1)依赖（ACF=0.41）、季度/半年周期（ACF=0.30/0.42）、年周期（VMD更有效捕获）。
证据：fig_seasonality_acf_data.json
发现8：模型的月度MAE呈冬低夏高特征（与需求绝对水平正相关），1月MAE仅6台，6月MAE达16台。
证据：fig3_error_analysis_data.json
发现9：ECA通道注意力在浅层（Block1）起均匀增强作用，在深层（Block2）表现出选择性增强。
证据：Block1均值0.500≈基线，Block2均值0.647且全>0.5
发现10：组件间存在协同效应：VMD为CATCN和FS提供基础，三者贡献不可简单叠加。
证据：独立贡献和(96.7pp) > 实际差距(65.3pp)

8.2　核心结论

1. VMD分解是必要前提（ΔR²=−65.3pp），将非平稳问题转化为平稳子问题
2. CATCN是关键增量（ΔR²=−18.1pp），通过局部特征+注意力引导双重机制增效
3. 残差跳连保障训练稳定（ΔR²=−8.0pp），降低输出尺度+提供先验基线
4. 特征筛选提升泛化能力（ΔR²=−5.3pp），消除噪声冗余、抑制过拟合
5. 四者构成协同体系：VMD奠基 → CATCN增效 → Skip稳优 → FS提纯

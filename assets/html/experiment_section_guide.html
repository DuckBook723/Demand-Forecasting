3 实验结果与分析

3.1 实验环境与参数配置

全部实验在统一软硬件环境下完成，以保证结果可比性。硬件平台为 NVIDIA GeForce RTX 4050 Laptop GPU，CUDA 版本 12.8；软件环境为 Python 3.11，PyTorch 2.11.0。随机种子固定为 42，PyTorch 后端启用确定性模式（deterministic=True）并关闭 benchmark，避免 GPU 加速引入的随机性干扰。

3.2 评价指标

采用均方根误差（RMSE）、平均绝对误差（MAE）、平均绝对百分比误差（MAPE）与决定系数（R²）四项指标综合评估预测性能：

RMSE = √(1/N Σ(ŷᵢ − yᵢ)²) ,   MAE = 1/N Σ|ŷᵢ − yᵢ|

MAPE = 100%/N Σ|ŷᵢ − yᵢ|/yᵢ ,   R² = 1 − Σ(ŷᵢ − yᵢ)² / Σ(yᵢ − ȳ)²

其中 RMSE 与 MAE 反映预测值与真实值的绝对偏差，MAPE 提供无量纲的相对误差度量，R² 衡量模型对目标变量变异的解释能力。R² 越接近 1，表明模型拟合优度越高；R² 为负则意味着模型预测效果劣于简单均值基准。

【指导建议】
1. 公式编号建议统一为式（3-1）至式（3-4），与第二章公式编号连续。
2. 若数据中存在零值或极小值导致 MAPE 异常，需在此说明"样本中无零需求记录，MAPE 计算有效"。
3. 不要遗漏 R² 为负的物理含义解释，后续 Fair-BiLSTM 的负 R² 需要此定义支撑分析。
4. 中文核心期刊通常要求公式使用 MathType 或 LaTeX 排版，HTML 中可用 <span class="formula"> 标记，最终投稿时替换为期刊模板格式。

2. 不要仅用"下降""降低"等笼统词汇，应给出具体数值差（如"降幅达 0.6530"），增强说服力。

3.5 对比实验

为全面评估所提框架的竞争力，选取统计模型（ARIMA）、传统机器学习模型（XGBoost）、深度学习模型（LSTM-diff、Fair-LSTM、Fair-BiLSTM）以及 VMD 与 LSTM 的串接模型（VMD-LSTM v2）作为基线，在相同数据集划分下独立运行。对比结果如表 3-4 所示。

所提模型在所有对比方法中取得最优的 RMSE、MAE、MAPE 与 R²。与次优的 VMD-LSTM v2 相比，R² 提升 0.0223，RMSE 降低 28.3，表明在 VMD 分解基础上引入 CATCN 局部编码、TA-BiLSTM 全局依赖建模与门控自适应融合，能够进一步挖掘模态分量中的互补信息。XGBoost 作为梯度提升树的代表，R² 仅为 0.6149，其特征重要性分析显示 demand_lag_1 与 wind_speed 占据主导，说明树模型虽能捕捉部分非线性关系，但对时序依赖的建模能力有限。LSTM-diff 采用差分预测策略，R²=0.5691，与 XGBoost 处于同一水平，表明单一 LSTM 架构难以同时驾驭长期趋势与短期波动。ARIMA 作为经典统计模型，R²=0.5405，对非线性、非平稳序列的刻画能力明显不足。

Fair-LSTM 与 Fair-BiLSTM 为公平对比实验，二者与本文主模型使用相同的输入维度与残差跳连策略，但分别采用单层 LSTM 与双向 LSTM 直接编码，无 VMD 分解、无 CATCN、无门控融合。Fair-LSTM 的 R² 仅为 0.3231，Fair-BiLSTM 甚至出现负 R²（−0.0316），预测效果劣于简单均值基准。该结果有力证明：在月度需求预测任务中，单纯增加 LSTM 层数或引入双向结构并不能提升性能，反而因参数增加与梯度传播困难导致过拟合；VMD 分解与双分支融合机制才是精度提升的关键来源。

【指导建议】
1. 对比实验表格建议按 R² 降序排列，最优模型置顶，便于审稿人快速定位。
2. VMD-LSTM v2 是本文最重要的"强基线"，分析时应单独成段，明确其 R²=0.8635 与主模型 0.8858 的差距（0.0223）即为 CATCN+TA-BiLSTM+门控融合的增量贡献。
3. Fair-LSTM/BiLSTM 的负 R² 是亮点，但分析需谨慎：不要贬低 LSTM 本身，而应强调"在本文任务设定下（小样本、多尺度、非平稳），单纯 LSTM 架构不足以胜任"。
4. XGBoost 的特征重要性结果（demand_lag_1 居首）可在正文中引用，作为"树模型依赖滞后特征、缺乏时序结构建模"的佐证。
5. ARIMA 参数量为 4，与深度学习模型相差 4 个数量级，可在分析中补充"参数量极少但精度有限，印证了该任务需要非线性深度建模"的对比逻辑。

3.6 综合分析与讨论

综合消融与对比实验结果，可得出以下结论：（1）VMD 模态分解是模型性能的首要来源，其将非平稳需求序列解耦为可解释的窄带分量，显著降低了后续深度网络的拟合难度；（2）CATCN 与 TA-BiLSTM 分别承担局部敏感模式与长程全局依赖的提取职责，二者通过门控机制自适应融合，避免了单一架构的信息瓶颈；（3）残差跳连与特征筛选虽贡献度次于上述模块，但在小样本场景下对抑制过拟合、稳定预测轨迹具有不可忽视的作用；（4）与统计模型、机器学习模型及常规深度学习模型相比，所提框架在 R²、RMSE、MAE、MAPE 四项指标上均取得最优，验证了其在电网物资月度需求预测任务中的有效性与先进性。
